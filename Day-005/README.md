Question: Find the First Occurrence

Given a sorted array and a target value, return the index of the first occurrence of the target.

If the target is not present in the array, return -1.

Example 1
Input:
nums = [1, 2, 2, 2, 3, 4, 5]
target = 2

Output:
1
Example 2
Input:
nums = [1, 2, 3, 4, 5]
target = 6

Output:
-1
