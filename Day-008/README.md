Question: Find Minimum in Rotated Sorted Array

You are given a sorted array that has been rotated at some unknown position.

Find the minimum element in the array.

You must solve it using Binary Search.

Example 1
Input:
nums = [3, 4, 5, 1, 2]

Output:
1
Example 2
Input:
nums = [4, 5, 6, 7, 0, 1, 2]

Output:
0
Example 3
Input:
nums = [11, 13, 15, 17]

Output:
11
